## 一、新增玩法（底栏「玩法」）

三个独立玩法，共用一套**独立 USDT 权益**（初始 10,000），与交易账户的保证金账户互不影响。

### 1. 事件合约（概率定价份额制 / Gate 口径）

- **周期**：5 分钟 / 15 分钟 / 1 小时 / 4 小时（Gate 无 1 分钟档，故不提供）
- **份额价 0.01–0.99 = 隐含概率**，1 张 = 1 USDT 兑付
- **结算价 = 整个周期的 TWAP**：周期内全部 1m K 线等权均价（5m→5 根、1h→60 根、4h→240 根）
- 判定：**结算价 ≥ 目标价判涨**（含等于）
- 手续费 0.1%/边；最小 6 张 / 5 USDT
- **报价随行情与剩余时间变化**：`p = Φ((μ−目标价)/σ)`，其中 μ 为已走完根与剩余根的时间加权均值、σ 随窗口填满而收敛
  - 结果：轮次开始时 ≈0.5；**越接近结算越极端**（趋近 0.01 / 0.99）；**均价穿过目标价时立刻翻转**
- 结算卡包含：目标价 / 结算价 / 基点差 / 你的判断 / 兑付与净盈亏

### 2. 事件合约（固定赔率制 / Binance 口径）

- 支付率 **80%**，盈亏平衡胜率 **55.56%**
- 赢 = 本金 × 1.8；**持平退本金**；输归零；无手续费；**不支持提前平仓**
- 周期 10m / 30m / 1h / 4h / 1d
- 单笔 5–250 USDT（同时受权益 5% 约束）

### 3. 期权（欧式现金结算）

- **只能做买方**，最大亏损 = 权利金
- 期限 1h / 4h / 1d / 3d / 7d / 30d
- 行权价：平值 ±8 档，间距按期限取现价 0.25% / 0.75% / 1.5% / 3%
- 定价：Black-Scholes + 实测年化波动率；展示 **delta / theta / vega / IV** 与人话解释
- 结算价 = 到期前 min(30, 期限) 根 1m 均价
- 行权费 = min(结算价值 × 0.015%, 实值额 × 10%)
- **期限按剩余可回放长度过滤**：数据不足以到期时该项置灰，避免白付权利金

### 玩法通用

- **模拟 Tick（默认开启，无开关）**：1 分钟 = 12 个 5 秒 tick；**现实 1 秒 = 行情 5 秒**，1× 下 12 秒走完 1 分钟
- 现价、报价、K 线最后一根（未收完的 K 线）都按 tick 更新
- 回放控制：**暂停 / 继续**、**1× 2× 4× 8× 倍速**、**⏩ 跳到结算**
- 品种与起点：BTCUSDT / ETHUSDT，可选起始月份，**跨月自动接续**
- 护栏：单笔 ≤ 权益 5%（下限 5 USDT，避免亏损后无法下单）、日亏 ≤ 权益 20%（按 UTC 跨日重置）

## 五、修复

- 事件合约报价此前用「目标价恒等于现价」，导致隐含概率长期贴 0.5、看不到极端值与翻转 → 改为**结算均价概率模型**
- 单笔上限用「权益 5%」且无下限，权益下跌后连 5 USDT 最小本金都无法下单 → 增加下限
- 日亏损上限原先只作用于固定赔率 → 三个玩法的亏损统一计入
- 期权超长期限在剩余回放不足时仍可下单（永远等不到结算）→ 按剩余长度过滤

## 六、已知限制（上架说明需如实保留）

1. 玩法权益与持仓**仅保存在本次运行内**，重启 App 重置
2. 事件合约**不支持提前平仓**；固定赔率按真实口径同样不支持
3. 玩法行情为**历史回放**，非实时行情；Tick 为 OHLC 确定性插值，**不是真实成交序列**
4. 交易账户（保证金/强平）与玩法权益相互独立，不共享余额
5. 本应用为**模拟器**，全部为虚拟记账单位，不涉及真实资金，不构成任何投资建议
