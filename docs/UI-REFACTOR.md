`design_recommend("金融交易模拟器 App 深色 高密度 行情K线 加密货币 玩法下注",
variance=4, motion=2, density=8)` 返回：

## 2. 采纳

## 3. 刻意不采纳（附理由）

| 配方建议 | 不采纳的理由 |
| --- | --- |
| 强调色 `#8B5CF6`（紫） | 与配方**自己的反模式**冲突（"AI purple/pink gradients"）。金融 CTA 继续用金色。 |
| 标题字体 Orbitron | 装饰性显示体，数字密集页面可读性差；价格/金额用等宽更合适。 |
| 纯黑背景 | 配方本身也要求避免 `#000000`（OLED 拖影）；已用深藏青。 |
